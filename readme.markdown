## 📋 Sobre o Projeto

O MoneyGrow-FI é uma aplicação web desenvolvida durante o curso Alura + Google Gemini, que proporciona uma análise completa de investimentos em renda fixa. A plataforma permite comparar diferentes tipos de ativos financeiros utilizando dados reais do mercado brasileiro, auxiliando investidores a tomar decisões mais informadas para a construção de seu patrimônio.

## 🚀 Funcionalidades

- **Análise Comparativa**: Gráficos de linha que permitem comparar o desempenho dos principais ativos de renda fixa do mercado brasileiro
- **Monitoramento Temporal**: Acompanhamento do rendimento dos investimentos ao longo de diferentes períodos
- **Tabelas Analíticas**: Visualização detalhada da rentabilidade líquida média e rentabilidade mensal de cada tipo de investimento
- **Dados Atualizados**: Consumo da API do Banco Central do Brasil para obtenção de índices atualizados

## 💻 Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript
- **Dados**: API do Banco Central do Brasil
- **Visualização**: Gráficos dinâmicos e tabelas interativas

## 🔄 APIs Integradas

O MoneyGrow-FI utiliza as APIs oficiais do Banco Central do Brasil para obter dados precisos e atualizados sobre os principais índices financeiros do mercado, garantindo que as análises realizadas reflitam a realidade atual do mercado financeiro brasileiro.

## 📊 Exemplo de Uso

1. Selecione os tipos de investimentos que deseja comparar
2. Defina o período de análise
3. Visualize os dados comparativos em gráficos e tabelas
4. Utilize as informações para embasar suas decisões de investimento

## ⚠️ Avisos Importantes

Este aplicativo foi desenvolvido apenas para fins educacionais e comparativos. As informações disponibilizadas:

- Não constituem recomendação formal de investimento
- Não substituem a orientação de um profissional financeiro qualificado
- Devem ser utilizadas apenas como referência para estudos sobre renda fixa
